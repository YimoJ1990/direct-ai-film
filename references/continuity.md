# 参考职责、物理状态与衔接

## 资产职责

| 类型 | 负责锁定 | 不负责 |
|---|---|---|
| 人物 | 身份、年龄感、发色发型、身体比例 | 素材原衣服、原场景、原姿势 |
| 服装 | 款式、颜色、材料、明确的鞋与配件 | 原模特脸、原模特身材 |
| 环境 | 装修语言、家具、空间关系、材料、光线方向 | 固定拍摄角度、原图构图 |
| 产品/关键道具 | 形状、比例、关键结构、图案、品牌 | 没有授权的剂量、功效或新版本 |
| 故事板 | 构图、出场角色、动作瞬间 | 把真人片变为线稿风格 |
| 衔接帧 | 已采用画面的实际位置、姿态、状态、色温 | 新身份、失真模糊、唯一面部细节 |

人物与服装默认分开输入。连衣裙素材图可以无人平铺；视频里“她手中拿着裙子”是画面要求，不意味着上传图必须人物拿裙子。主体/服装不应互相污染。首帧位置单列，不占参考图编号；若入口把首帧计为图1，以实际工具编号重新输出完整映射。

镜头切换后桌杯的位置可以在画面中改变，但其世界空间位置不能跳变。头部写“不照搬场景图机位”，每镜写具体机位；不能同时“锁定参考图角度”。对话先确定轴线，再在同一侧做正反过肩与双人镜；如要越轴，设计明确过轴镜，不默认禁止所有机位变化。

按模型实际支持的输入上限编排，未知时不编造上限。输入太多时先明确保留关键资产，提出同一角色换装验证图/分镜首帧等方案，但人物与服装分开是本用户默认偏好，合并须明确解释并获认可。

## 物理状态台账

给关键道具记录每镜开始/结束：位置、归属、朝向、开合、数量、是否接触。

- 衣架：固定刚性三角形，钩子连接正确；取衣过程脆弱可省略切镜。不能前镜衣架在墙上，后镜不解释就握在手中。
- 连衣裙：悬挂→双手握上方两侧→比在身前→干燥台面→折叠；人物穿着不变。
- 手机：屏幕/背面方向明确，握点不翻转；未录制与已录制不能冲突；拿手机前交代口袋/桌面来源。
- 瓶子：产品身份唯一；闭合、未开封和开盖使用是不同状态。只被批准的段落才显示开盖，瓶盖不与滴管融合。
- 跑步机：运行→按停→减速→停稳→下机；四秒做不完时拆镜或延时，勿同时停机和迈下。
- 镜子：倒影只有本人，动作同步；摄影机避开不合理穿镜，无额外人脸、错手与多肢。

## 检查已有视频

提取开头、切镜前后、动作峰值与最后实际帧；检查源分辨率、衣服实际颜色、机位、光向、出场者和道具终态。环境和衣服与文字草案不符时，按已采用视频修订后续，不责怪用户，也不假装已经一致。

- 同动作续接：末帧作为首帧，明确接下一个动作，不重复拿物/入场。
- 同地点换机位：用动作或视线接切，保持世界空间与轴线，非必须逐像素复制。
- 时间或地点变化：硬切/明确转场，勿强迫用末帧把不同空间糊成一个。
- 低清末帧：高清人物图锁脸，高清材质参考补细节，末帧只锁内容；说明文字“不继承模糊”不能保证模型恢复细节。按用户授权修复并检查偏移，或改用自然切镜。
- 衔接帧从视频导出供用户下载时保留源画面，不擅自裁切、重绘或插值后称高清。

返修一次优先改一个核心变量。若参考输入或动作改变，更新所有依赖镜头、故事板格与视频提示词；保持未涉及资产版本。
