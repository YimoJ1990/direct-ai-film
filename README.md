# AI 导演 Skill · direct-ai-film

将剧本、广告脚本和故事片段整理为具有导演节奏的分镜、纯线稿故事板、资产提示词和完整视频提示词。

## 支持的工作方式

- 从脚本开始：分析剧情、精简资产、设计分镜，审核后生成图片。
- 制作中单独调用：只写某一场的视频提示词、补场景或服装提示词、修改运镜、续接前段、修复道具连续性。
- 已有人物和产品时复用，不重复创造；人物身份与服装参考分开。
- 环境参考确定空间与材料，不固定视频机位；按动作和情绪安排快慢节奏。

## 使用

下载本仓库，将整个文件夹命名为 `direct-ai-film`，放入你的智能体支持的 skills 目录。支持 SKILL.md 的智能体从 [SKILL.md](SKILL.md) 开始读取。其他智能体也可以直接读取该文件，并按需读取 references 内的说明。图片生成需要宿主提供图像工具；视频提示词可独立使用，本技能不自带视频模型或商业API。

示例：

> 根据这份剧本做导演分镜，先给我审核，不生成图片。

> 只给第3场的完整视频提示词和输入清单，30秒，人物与服装分开输入。

> 这段运镜太平，保留剧情，重新安排快慢节奏与动作接切。

> 根据上一段末帧续接，保持人物服装、场景与道具状态连续。

## 文件

- `SKILL.md`：技能入口与工作流程。
- `references/`：导演方法、模板、连续性、审核和项目结构。
- `scripts/validate_project.py`：项目结构校验，运行 `python scripts/validate_project.py /path/to/project.json`。
- `agents/openai.yaml`、`assets/icon.svg`：支持相应宿主时使用的展示信息。

默认中文提示词、9:16真人实拍资产和视频、白底黑色纯线稿审核故事板。实际时长、画幅和输出风格遵从用户指令；具体模型限制按实际入口确认。

## 方法参考

参考 [lengyi Seedance 提示词设计方法](https://github.com/woyin2024/lengyi-seedance2.5-prompt/blob/main/README.zh.md) 的资产先行和多镜头表达思路；本技能包含独立编写的导演参考、审核流程、资产分离规则及校验脚本。
